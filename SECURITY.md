# Security

become-verify decides whether a BECOME proof passes, so a bug that lets a wrong or altered proof `PASS` is a security
problem. So is a download or a browser build that doesn't match this repository.

## Reporting

Please report privately with GitHub's **Report a vulnerability** button on this repository's
[Security tab](https://github.com/Beloved-Ecosystem-Inc/become-verify/security). Don't open a public issue. Include
the become-verify version (`v0.2.0` or a commit), how you ran it, and the smallest set of files that shows the
problem.

We'll acknowledge your report, keep you updated while we fix it, and credit you in the release notes if you'd like.

## Supported versions

The latest release. Fixes ship as a new release, built and attested by this repository's release workflow.
